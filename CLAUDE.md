# Claude Code Pointer

This is **LoogriGram Desktop**, a fork. Read `LOOGRIGRAM.md` first: it covers
the fork's state, the rules already settled with the user, how to build it,
and the traps in the tree and in CI that have each already cost a multi-hour
build.

Then read `AGENTS.md`, which is upstream's and remains canonical for code style
and repository-wide conventions. Where the two disagree, `LOOGRIGRAM.md` wins on
anything fork-specific.

The desktop work is finished and conserved as of 2026-09-20; active work is on
Android, in `../loogrigram-android`.
